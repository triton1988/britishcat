FAQ

How do I restore Premium on a new device?
Open Profile → Premium → "Restore Purchases" with the same Apple ID.

How do I move my progress?
Turn on iCloud on both devices with the same Apple ID. Progress syncs by itself.

How do I change the language?
Profile → Settings → "Your language".

The voice is silent or sounds poor.
Check the silent switch. For a better voice, download an English Premium voice: Settings → Accessibility → Spoken Content → Voices → English.

How do I delete all my data?
Profile → Settings → "Delete all progress". Premium stays.

常见问题

如何在新设备上恢复高级版？
使用同一个 Apple 账户，打开 个人资料 → Premium →“恢复购买”。

如何转移我的进度？
在两台设备上用同一个 Apple 账户打开 iCloud，进度会自动同步。

如何更改语言？
个人资料 → 设置 →“你的语言”。

没有声音或声音不好听。
请检查静音开关。想要更好的声音，可以下载高质量的英语语音：设置 → 辅助功能 → 朗读内容 → 声音 → 英语。

如何删除我的全部数据？
个人资料 → 设置 →“删除全部进度”。高级版会保留。

よくある質問

新しい端末でプレミアムを復元するには？
同じ Apple アカウントで、プロフィール → Premium →「購入を復元」を開いてください。

進行状況を移すには？
両方の端末で同じ Apple アカウントの iCloud をオンにしてください。進行状況は自動で同期されます。

言語を変えるには？
プロフィール → 設定 →「きみの言語」。

声が出ない、または聞き取りにくい。
消音スイッチを確認してください。より自然な声にするには、高品質の英語の声をダウンロードしてください：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語。

データをすべて削除するには？
プロフィール → 設定 →「進行状況をすべて削除」。プレミアムはそのまま残ります。
